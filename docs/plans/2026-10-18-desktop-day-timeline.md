# PCの日別スケジュール

- PCの月カレンダーで日付・「ほか」件数、または担当者表の日付見出しをクリックすると、その日を選択し、大きな日別ポップアップを開く。同じ月内は取得済み予定を使用。月外日付は新しい月の取得後に開く。
- 担当者を横列、00:00〜24:00を縦軸にする。担当者ヘッダー・終日枠・時間軸はスクロール中も固定。担当者が多い場合は横、時間は縦にスクロールする。
- 選択担当者は予定なしでも列を残す。担当者色と写真を共用する。Google／Microsoftはまとめ、重なる予定は担当者内で横に分ける。
- 終日・日またぎ・排他的終了を維持。短時間予定は選択できる高さと表示用レーンで配置し、詳細には元の日時を渡す。
- スマホは通常タップで選択、長押しで担当者アコーディオンの既存動作を維持。開いたまま画面幅が変わった場合は端末幅に合わせて表示を切り替える。
- API・認証・同期・保存データは変更しない。commit/push/公開は今回の実装に含めない。

検証: PCクリック・同月再取得なし・月外クリック・未選択者除外・空担当列・重なり/短い連続予定・終日/日またぎ・縦横スクロールと固定ヘッダー・モバイル長押し回帰。npm test、npx tsc --noEmit、npm run build。
