# モバイルのメイン表示切替と予定表示の簡素化

- PC・モバイルともメイン画面上部に「月／担当」を表示する。初期表示は月。担当は既存の1週間の担当者表を共用し、担当者を行、日付を列として表の中で縦横にスクロールできる。
- 画面幅変更でも月／担当の選択を維持する。期間送りと今日は表示中のモードに従い、担当者の絞り込みでは再取得しない。
- モバイルの選択日エリアと長押しポップアップは担当者別のアコーディオン一覧にする。日別の表示切替タブと不要な専用部品・スタイルを取り除く。
- PCの日別ポップアップは既存の担当者列・時間縦軸の時間割を維持。スマホの長押し解除クリック抑制、通常タップ、背景スクロール固定、閉じる操作を維持する。
- 通常カードから予定元ラベルとサービス名だけの場所placeholderを除く。実際の場所・件名は保持し、クリック後の詳細へは元のイベントを渡す。API・保存・同期・認証は変更しない。

検証: モバイルの月／担当切替、週送りと今日、担当者絞り込み時の再取得なし、幅変更時の表示維持、長押しポップアップにタブがないこと、詳細の原文維持、320・375・430pxとPCの表示・スクロール。npm test、npx tsc --noEmit、npm run build。commit/push/公開は含めない。
