# 担当者別の予定とスマホの長押し確認

- 担当者IDのハッシュによる10色振り分けを、全担当者一覧を基準とする重複なしの配色へ変更する。日付や担当者の表示フィルタを適用する前の一覧で割り当て、各ビュー・詳細・選択欄で共用する。
- 選択日の一覧をownerUserIdごとの初期閉じアコーディオンにする。見出しは氏名と件数、担当者内は終日先頭・開始時刻順。予定元は統合、同名や重複予定は維持する。
- スマホの日付を500ms長押しすると、その日の同じ一覧をスクロール可能なnative dialogに表示する。移動10px超・スクロールのpointercancel・指を離す・画面変更で長押しを中止し、長押し後のclickを通常選択にしない。
- 通常タップは従来の日付選択。Shift+F10でもポップアップを開ける。ダイアログは背景操作を抑え、閉じる・Escape・外側タップに対応。予定クリックは既存の詳細画面へ移る。
- 認証・API・同期・保存スキーマは変更しない。新たな通信・予定編集は追加しない。

検証: 12名以上の色の一意性・フィルタ/日付往復の色維持・ownerごとの混合source統合・長押し/短押し/スクロールキャンセル・ポップアップのスクロールとフォーカス復帰。npm test、npx tsc --noEmit、npm run build。320/375/430pxとPCで実画面確認。
